Setup & Verification

First-time setup (per station)

  1. Set the label size to match your stock (or pick a preset). QR and Code 128 each remember their own size.
  2. Print 1 test label and scan it into your tracking system to confirm it reads.
  3. In the browser's print dialog set Scale = 100% (Actual size), Margins = None, and headers/footers off; choose your Zebra printer.
  4. Bookmark the page — every setting is saved in the bookmark, so the station is configured for good.

Print quality

Bars/QR are snapped to whole printer dots and sized at native resolution (no image stretching). If a code scans reluctantly, adjust Darkness in the Zebra driver's Printing Preferences before anything else. Tuned for the Zebra GK420d (203 dpi); other Zebras work — set the DPI accordingly.

Verification & security

Runs 100% offline in this single file — asset numbers never leave the machine, and there is no install, login, or network call. The barcode engines self-test on every open and refuse to run if a check fails; every generated code has been round-trip decoded against the real tag formats. If a scanner ever reads a label differently than printed, stop and report it.
